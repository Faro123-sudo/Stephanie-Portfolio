# Learning Roadmap — Portfolio Qualification Plan

**Goal:** Be able to confidently discuss and demonstrate every skill in your portfolio within 4–6 weeks.

---

## Phase 1: Core Foundations (Week 1–2)

### Git & GitHub (2 days)
- [ ] **Day 1:** `git init`, `add`, `commit`, `push`, `pull`, `clone`, `status`, `log`
- [ ] **Day 2:** branching (`branch`, `checkout`, `merge`), pull requests on GitHub
- **Resource:** Atlassian Git Tutorial or GitHub Skills (free)

### Python + SQL (3 days)
- [ ] **Day 3–4:** Python — functions, classes, file I/O, list/dict comprehensions
- [ ] **Day 5:** SQL — `SELECT`, `JOIN`, `GROUP BY`, `HAVING`, subqueries
- **Practice:** Solve 10 Python exercises + 10 SQL problems on LeetCode (easy)

### JavaScript + HTML/CSS (3 days)
- [ ] **Day 6:** JS — DOM manipulation, fetch/async-await, array methods
- [ ] **Day 7:** CSS — Flexbox, Grid, responsive design (media queries)
- [ ] **Day 8:** Build a small interactive page (e.g., a to-do app) to tie it together

## How to Verify You're Ready

Before applying to jobs, you should be able to answer these without notes:

1. *"Tell me about your ECG project."* → 2-min structured answer
2. *"What Git workflow did your team use?"* → describe branching strategy
3. *"What's the difference between supervised and unsupervised learning?"* → clear example
4. *"Write a SQL query to find the top 5 customers by order value."* → can do it
5. *"How do you ensure your code is high quality?"* → mention testing, code review, CI
6. *"Explain a time you worked in a team."* → Agile, stand-ups, task coordination
